**Author:** Preeti Dudam (preetidudam)  

## Project Overview
This project is a multi-tier dealership web application built as part of the IBM Full Stack Software Developer Capstone. The platform allows nationwide car retailer customers to browse car dealerships across the United States, filter branches by state, view authentic customer reviews with automated sentiment analysis, and submit new vehicle purchase reviews.

## Architecture & Technology Stack
- **Frontend:** React, HTML5, CSS3, JavaScript (ES6+), Bootstrap
- **Backend (Web Framework):** Django, Python 3.10, SQLite
- **Backend (Microservices):** Node.js / Express, MongoDB
- **Sentiment Analysis Microservice:** Python Flask, NLTK / Watson NLU
- **DevOps & Deployment:** Docker, Kubernetes, GitHub Actions CI/CD, IBM Cloud Code Engine
